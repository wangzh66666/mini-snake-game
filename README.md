# 网页版贪吃蛇

一个使用 HTML、CSS 和原生 JavaScript 编写的轻量贪吃蛇游戏，无需安装依赖或构建工具。

## 功能

- 使用键盘方向键或 `W`、`A`、`S`、`D` 控制移动
- 支持屏幕方向按钮，方便在触屏设备上游玩
- 实时计分，并在本地保存最高分
- 检测撞墙和撞到自身
- 可暂停、继续、结束后重新开始
- 响应式布局，适配桌面与移动端

## 项目结构

```text
mini-snake-game/
├── index.html   # 页面结构、计分面板和游戏控件
├── style.css    # 页面布局、主题与响应式样式
├── script.js    # 游戏状态、绘制、输入和碰撞逻辑
└── README.md    # 项目说明
```

## 运行方式

本项目没有第三方依赖，可以直接双击 `index.html` 在浏览器中打开。

也可以在项目目录启动一个静态文件服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 操作说明

1. 点击“开始游戏”，或按任意方向键开始。
2. 使用方向键或 `W`、`A`、`S`、`D` 改变蛇的移动方向；不能直接反向移动。
3. 吃到红色食物得 10 分，蛇身会增长，移动速度也会略微提升。
4. 按空格键或页面上的“暂停”按钮可暂停/继续。
5. 撞到墙壁或自身后游戏结束，点击“再来一局”即可重新开始。
